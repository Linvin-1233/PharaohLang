## 概述

Ma'at（古埃及真理与秩序女神之名）是一门**图灵完备**的编程语言，其语法关键字和标识符源自**埃及圣书体**（Egyptian Hieroglyphs, Unicode U+13000–U+1342F）。编译器使用严格 TypeScript（`strict` 模式）编写，遵循经典的 Lexer → Parser → AST → Checker → Interpreter 流水线架构，零外部运行时依赖。

这是一个**玩笑项目**，但 ~~为了显得更高级~~ 我们把它包装成了一项**严肃的语言工程**。毕竟，如果非要在圣书体和拉丁字母之间选一个写代码，为什么不选那个更有博物馆气息的呢？

## 编译器架构

```
源文件 .maat → Lexer → Token[] → Parser → AST → Checker → Interpreter → 输出
```

各阶段严格分离，互不混杂：
- **Lexer** — Unicode 感知的词法分析器，处理代理对，剥离注释
- **Parser** — 递归下降语法分析器，生成 AST，带错误恢复
- **Checker** — 静态语义检查器，报告未定义变量、未使用变量、参数不匹配等问题
- **Interpreter** — 树遍历解释器，词法作用域环境链，支持模块导入递归执行
